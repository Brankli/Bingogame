USER CREDIT SYSTEM - MANUAL TESTING GUIDE
================================================================================

PREREQUISITES:
- Backend running: npm run start:dev
- Frontend built: cd client && npm run build
- Access to admin account

================================================================================
TEST SCENARIO 1: Add Credits to User
================================================================================

1. Login as ADMIN
2. Navigate to: Admin Dashboard → User Management
3. Find any user in the table
4. Look for the "Credits" column (should show 0 initially)
5. Click the 🪙 (coin) icon button in the Actions column
6. In the "Add Credits" dialog:
   - Enter amount: 10
   - Enter notes: "Testing credit system"
   - Click "Add Credits"
7. EXPECTED RESULT:
   ✓ Dialog closes
   ✓ Toast message: "Added 10 credits successfully!"
   ✓ User's Credits column now shows: 10
   ✓ Games Played column shows: 0

================================================================================
TEST SCENARIO 2: Start Game (Credit Deduction)
================================================================================

1. Login as the USER who has credits (from Test 1)
2. Navigate to any Room (e.g., Room 1)
3. Look at the top section - verify "GAME NUMBER: 0"
4. Register some cards (click on card numbers to select)
5. Click "Start Game" button
6. EXPECTED RESULT:
   ✓ Game starts successfully
   ✓ "GAME NUMBER" updates to: 1
   ✓ Check console (F12): Should see credit update logs
   ✓ User now has 9 credits remaining (10 - 1)

7. Finish the game (or reset)
8. Register cards again and click "Start Game"
9. EXPECTED RESULT:
   ✓ "GAME NUMBER" updates to: 2
   ✓ User now has 8 credits remaining

================================================================================
TEST SCENARIO 3: Credit Exhaustion (Block Game Start)
================================================================================

1. As ADMIN, set user credits to 1:
   - Go to User Management
   - Click 🪙 to add credits
   - (User should have 1 credit)

2. Login as USER
3. Navigate to room and register cards
4. Click "Start Game" (this uses the last credit)
5. EXPECTED RESULT:
   ✓ Game starts
   ✓ "GAME NUMBER" increments
   ✓ Credits: 0

6. Try to register cards and click "Start Game" again
7. EXPECTED RESULT:
   ✓ "Start Game" button is DISABLED (greyed out)
   ✓ Toast error: "No credits remaining. Contact admin to top up."
   ✓ Game does NOT start

TEST SCENARIO 4: Reset Games Played Counter
================================================================================

1. Login as ADMIN
2. Navigate to: Admin Dashboard → User Management
3. Find a user with gamesPlayed > 0
4. Click the 🔄 (refresh) icon in Actions column

   "Reset games played counter for [username]?"

7. EXPECTED RESULT:
   ✓ Dialog closes
   ✓ Toast: "Games played counter reset successfully!"
   ✓ User's "Games Played" column shows: 0
   ✓ User's "Credits" column remains UNCHANGED

================================================================================
COMMON ISSUES & TROUBLESHOOTING
================================================================================

ISSUE: "Start Game" not disabled when credits = 0
FIX: Check browser console for errors, refresh page

ISSUE: Game counter not incrementing
FIX: Check socket connection (F12 → Network → WS tab)

ISSUE: Credits not updating after game start
FIX: Verify backend logs show credit deduction, check socket events

ISSUE: Transaction history empty
FIX: Verify UserCreditTransaction entity is registered in database config

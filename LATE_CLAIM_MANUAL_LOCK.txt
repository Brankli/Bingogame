================================================================================
LATE CLAIM MANUAL LOCK FEATURE
================================================================================

IMPLEMENTATION DATE: October 15, 2026
FEATURE: Manual Lock Button for Late Claims

================================================================================
PROBLEM SOLVED
================================================================================

OLD BEHAVIOR:
- Player calls "BINGO" after pattern completed (late claim)
- System automatically locks the card
- ❌ Too harsh - no second chance
- ❌ No flexibility for legitimate delays

NEW BEHAVIOR:
- Player calls "BINGO" late
- System shows "LATE CLAIM" warning
- Manager sees card details
- Manager manually decides whether to lock
- ✅ More fair - players get second chances
- ✅ Manager has control

================================================================================
HOW IT WORKS
================================================================================

STEP 1: Player Calls BINGO Late
- Pattern was completed on previous number
- Player calls on current number (late)

STEP 2: System Detects Late Claim
- Backend returns: lateClaim: true
- Frontend shows: "❌ LATE CLAIM!" error toast
- Audio: "Late claim rejected. You must call BINGO immediately."
- Visual: Red alert in verification card

STEP 3: Manager Reviews Card
- Card details modal opens automatically
- Shows the card grid with pattern highlighted
- Green cells = numbers called
- Highlighted pattern visible

STEP 4: Manager Decides
Option A: Give Second Chance
- Don't click "Lock Card" button
- Close modal
- Player can try again on future patterns
- Card remains unlocked

Option B: Lock the Card
- Click red "Lock Card" button
- Card is locked for current match only
- Player cannot win this match anymore
- Lock cleared when match ends

================================================================================
WHEN TO LOCK VS NOT LOCK
================================================================================

LOCK THE CARD IF:
✅ Player consistently calls late (pattern cheating)
✅ Player saw they lost and trying anyway
✅ Clear abuse/bad faith claim
✅ Multiple late claims from same player

DON'T LOCK IF:
✅ First time late claim
✅ Network delay / connection issue
✅ Language barrier / confusion
✅ Legitimate mistake
✅ Close timing (1-2 numbers late)

================================================================================
UI LOCATIONS

2. Alert Box (In Verification Card)
   Icon: ⚠️ Alert circle
   Message: "This pattern was completed earlier. You must call BINGO..."

   Location: Bottom right, next to X button
   Color: Red
   Icon: 🔒 Lock
   Text: "Lock Card"

TESTING SCENARIO
================================================================================

Test Late Claim Flow:

1. Setup:
   - Start a game with pattern "horizontal"
   - Register card #1

2. Create Late Claim:
   - Call numbers until card #1 completes Row 1
   - Note the completing number (e.g., B-5)
   - Call 2-3 more numbers
   - Now verify card #1

3. Expected Result:
   ❌ "LATE CLAIM!" toast appears
   ❌ Red alert shows in verification card
   ✅ Card details modal opens
   ✅ "Lock Card" button is visible (red, bottom right)
   ✅ Pattern is highlighted on card grid

4. Test Option A (Give Second Chance):
   - Don't click "Lock Card"
   - Close modal (X button)
   - Result: Card #1 is NOT locked
   - Player can try again on future patterns

5. Test Option B (Lock Card):
   - Click red "Lock Card" button
   - Toast: "Card 1 locked for this match"
   - Modal closes automatically
   - Try to verify card #1 again
   - Result: "Card is locked" error

6. Test Lock Clearing:
   - Click "Reset Board" or "Finish Game"
   - Start new game
   - Verify card #1
   - Result: Card is unlocked (lock was temporary)

================================================================================
COMPARISON: LATE CLAIM VS INVALID CLAIM
================================================================================

LATE CLAIM:
- Pattern WAS valid, but called late
- Shows winning pattern
- Manager decides whether to lock
- "Lock Card" button appears
- Default: No lock (give second chance)

INVALID CLAIM:
- Pattern is NOT valid at all
- Wrong pattern / not complete
- Automatically locks immediately
- No "Lock Card" button needed
- Always locks (clear abuse)

================================================================================
BENEFITS
================================================================================

✅ Fairer to Players:
   - Mistakes don't result in immediate punishment
   - Network delays don't auto-lock cards
   - First-time mistakes forgiven

✅ Manager Control:
   - Admin decides what's acceptable
   - Flexibility for special cases
   - Can enforce rules as needed

✅ Temporary Locks:
   - Locks only last current match
   - Fresh start each game
   - No permanent penalties

✅ Better User Experience:
   - Less frustration
   - More forgiving system
   - Encourages continued play
